# กลุ่มแชทเกม (Vercel + Supabase)

## 1) ตั้งค่า Supabase (ฟรี)
1. สมัคร supabase.com → New project
2. **Authentication → Sign In / Providers → เปิด "Allow anonymous sign-ins"** (สำคัญ)
3. **SQL Editor** → วางเนื้อหา `schema.sql` (แก้รหัสผู้ดูแลบรรทัดที่ 4 ก่อน) → Run
4. **Project Settings → API** → คัดลอก Project URL และ anon public key ไปใส่ใน `config.js`

## 2) อัปขึ้น Vercel
- วิธีง่ายสุด: ติดตั้ง Node แล้วรันในโฟลเดอร์นี้ `npx vercel --prod` (ล็อกอิน แล้วกด Enter ตามค่าเริ่มต้น)
- หรือ: อัปโฟลเดอร์ขึ้น GitHub → vercel.com → Add New Project → Import → Framework: **Other** → Deploy

## 3) ใช้งาน
- เปิดลิงก์ → กด ⚙️ → ใส่รหัสผู้ดูแล → วางรายชื่อในเกม (บรรทัดละชื่อ) → บันทึก (ใส่ชื่อตัวเองด้วย)
- ส่งลิงก์ให้สมาชิก ใครกรอกชื่อตรงรายชื่อและยังไม่ถูกใช้ จึงเข้าแชทได้
- ชื่อถูกใช้ผิดคน/เปลี่ยนเครื่อง: ⚙️ → กด "ลบ" ที่ชื่อนั้น แล้วให้เข้าใหม่

หมายเหตุ: การยืนยันตัวตนอิงชื่อในเกมเท่านั้น (ใครรู้ชื่อและเข้าก่อนก็ได้ชื่อนั้น) รูปในแชทเป็นลิงก์สุ่มที่เดายาก แต่ใครมีลิงก์รูปก็เปิดได้
